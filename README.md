# odin-recipes

This is a project labeled Recipes and will serve as an introductory project. It will showcase my understanding and foundation in the programming language HTML. This project requires us to build a small website that showcases some of our favorite dishes and recipes. Each recipe page will showcase a description of the dish, the ingredients, and the steps to make the dish. When it comes to the actual programming, I have learned that most, if not all, HTML files will follow a bread-and-butter boilerplate. On top of that, I have learned how to create headings, paragraphs, unordered lists, ordered lists, and how to link webpages together. This project has taught me the basics of HTML, and continuing the Odin Project will not only improve my understanding of web development but will also build upon my early projects such as this one.
